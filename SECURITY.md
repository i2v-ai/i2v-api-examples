# Security

Use [private vulnerability reporting](https://github.com/i2v-ai/i2v-api-examples/security/advisories/new) for a security issue in this repository. Include the affected example or version, the environment, and minimal steps with synthetic data or test credentials. Keep secrets and customer content out of public issues and attachments.

See [account and connection controls](https://i2v.ai/docs/mcp/account-and-access) to revoke an API key or an MCP connection.
